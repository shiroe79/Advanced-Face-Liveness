# Introduction 
This is going to be a web-based multi-modal biometric attendance management system that utilizes facial recognition and fingerprint scanning to automate attendance tracking.

## Tools will include

- React
- Node.js
- PostgreSQL ...


## Setup Instructions

```bash
# Node.js 23.6.0 or higher is required for this project
git clone https://github.com/shiroe79/Advanced-Face-Liveness
cd Advanced-Face-Liveness
npm install
```
